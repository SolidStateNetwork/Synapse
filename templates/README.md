# 🎨 Unified Design Templates (`SolidStateNetwork/Synapse`)

Dieses Verzeichnis enthält die flottenweit synchronisierten, aber **Clean-Room-isolierten** Design-Templates des SolidStateNetwork-Ökosystems:

1. **`synapse-canvas`** (`#14161a` `.nb-canvas-grid` Interactive Node-Graph + Collapsible Sidebar + Right Copilot Drawer) – genutzt von **`Synapse`** und **`Command-HQ`**.
2. **`signal-terminal`** (Taktisches OKLCH-Farbsystem & Multi-Palette-Engine) – genutzt von **`Template_Signal`** und **`Command-HQ`**.
3. **`werkblick-handwerk`** (Warm Daylight Craftsmanship `#f6f4ef` / `#1e5f4b` Meister-Grün / `#c86428` Werkstatt-Kupfer) – genutzt von **`Werkblick`** und **`Anvil`**.

## Dateien
- [`design-tokens.json`](design-tokens.json): Maschinenlesbare Token-Spezifikation aller 3 Design-Linien (`v2.0.0`).
- [`theme-bridge.css`](theme-bridge.css): CSS Custom Properties (`[data-ssn-template="..."]`) und `.nb-canvas-grid` Utility-Klasse.
